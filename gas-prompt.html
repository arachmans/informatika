Buatkan aplikasi Google Apps Script lengkap untuk SISTEM PRESENSI DAN PENGELOLAAN NILAI SISWA berbasis Web App.

## KONTEKS
Aplikasi digunakan sekolah untuk mencatat kehadiran siswa dan mengelola nilai akademik. Database menggunakan Google Sheets, antarmuka berupa Web App (HTML/CSS/JS) yang diakses guru dan admin.

## STRUKTUR DATABASE (Google Sheets)
Buat spreadsheet dengan sheet berikut:
1. Users    : username, password, nama, role (admin/guru), mapel yang diampu
2. Siswa    : NIS, nama, kelas, jenis kelamin, wali murid (nama & no HP)
3. Kelas    : kode kelas, nama kelas, wali kelas
4. Mapel    : kode mapel, nama mapel
5. Presensi : tanggal, NIS, nama, kelas, status (H/S/I/A), keterangan, dicatat oleh
6. Nilai    : NIS, nama, kelas, mapel, jenis penilaian (Tugas/UH/UTS/UAS), skor, semester, tahun ajaran

## ROLE PENGGUNA
1. Admin : kelola data master (siswa, kelas, mapel, users), lihat semua rekap
2. Guru  : input presensi per kelas, input nilai sesuai mapel yang diampu

## FITUR UTAMA

### A. Autentikasi
- Halaman login dengan validasi username & password
- Manajemen session, redirect sesuai role setelah login
- Tombol logout

### B. Modul Presensi
- Input presensi harian: pilih kelas → tampil daftar siswa → set status Hadir/Sakit/Izin/Alpa per siswa
- Riwayat presensi dengan filter tanggal & kelas
- Rekap kehadiran per siswa (persentase kehadiran) per bulan/semester

### C. Modul Nilai
- Input nilai per kelas & mapel (bentuk grid: daftar siswa × jenis penilaian)
- Edit dan hapus nilai
- Perhitungan nilai akhir otomatis: Tugas 30% + UH 30% + UTS 15% + UAS 25% (simpan bobot ini sebagai konfigurasi agar mudah diubah)
- Ranking nilai per kelas

### D. Dashboard & Laporan
- Dashboard: total siswa, rekap kehadiran hari ini, rata-rata nilai per mapel
- Laporan presensi per kelas/siswa
- Laporan rapor mini per siswa (semua nilai + kehadiran)

## ANTARMUKA
- Responsive (desktop & mobile-friendly, guru sering akses via HP)
- Desain bersih & modern, sidebar navigasi: Dashboard, Presensi, Nilai, Data Master (admin), Laporan
- Tabel dilengkapi pencarian & filter

## SPESIFIKASI TEKNIS
- Backend: pisah beberapa file .gs (Auth.gs, Presensi.gs, Nilai.gs, MasterData.gs, Laporan.gs, Code.gs sebagai router)
- Frontend: file HTML terpisah (Login.html, Dashboard.html, Presensi.html, Nilai.html, MasterData.html, Laporan.html) + fungsi include()
- Komunikasi frontend-backend via google.script.run
- Validasi input di sisi client dan server
- Error handling dengan try-catch dan pesan informatif
- appsscript.json dengan OAuth scopes minimal

## OUTPUT YANG DIHARAPKAN
1. Kode lengkap setiap file (sebutkan nama file dengan jelas)
2. Struktur spreadsheet yang harus dibuat (nama sheet & kolom)
3. Langkah deploy: Deploy as Web App, pengaturan Execute as & Who has access
4. Panduan penggunaan singkat

Karena aplikasi ini kompleks, bangun secara bertahap:
TAHAP 1: setup database + autentikasi + framework UI
Setelah selesai, saya akan minta TAHAP 2 (modul presensi), TAHAP 3 (modul nilai), TAHAP 4 (laporan & dashboard).
Tampilkan kode lengkap tanpa dipangkas.
TAHAP 1

Setup Dasar & UI

Pada tahap ini, kita menyiapkan struktur database di Google Sheets dan membuat kerangka utama aplikasi web, termasuk sistem login dan *routing* halaman.

Database (Sheets)

  • Users: Username, Password, Role, Nama, Mapel
  • Siswa: NIS, Nama, Kelas, dll.
  • Kelas: Kode Kelas, Nama Kelas
  • Mapel: Kode Mapel, Nama Mapel

File Code Utama

  • Code.gs Router sistem (doGet)
  • Auth.gs Validasi login
  • Index.html Kerangka layout & Sidebar
  • Login.html Form Login
TAHAP 2

Modul Presensi

Fokus pada pencatatan kehadiran siswa. Data disimpan ke dalam sheet Presensi.

Komponen yang dibuat:

  • Presensi.gs: Backend untuk mengambil daftar siswa berdasarkan kelas dan menyimpan array presensi secara *batch*.
  • Presensi.html: Antarmuka form presensi dengan UI radio button (Hadir, Sakit, Izin, Alpa) dan tombol submit asinkronus via google.script.run.
TAHAP 3

Modul Nilai Akademik

Menambahkan fitur input nilai (Tugas, UH, UTS, UAS). Data ini akan masuk dan tersimpan pada sheet Nilai.

Komponen yang dibuat:

  • Nilai.gs: Logic backend untuk menerima dan menyimpan data nilai ujian siswa ke database.
  • Nilai.html: Form UI dinamis yang menyediakan dropdown Kelas, Mata Pelajaran, Jenis Penilaian, Semester, dan Tahun Ajaran.
TAHAP 4

Dashboard & Master Data

Tahap penyempurnaan yang menggabungkan seluruh fitur menjadi satu kesatuan utuh. Menambahkan visualisasi data di Dashboard dan fitur cetak rapor.

Dashboard Dinamis

Menampilkan statistik total siswa, kelas, dan kehadiran *real-time*.

Cetak Rapor

Mengkalkulasi Nilai Akhir (NA) dan menampilkan PDF Rapor Mini.

Master Data

Fitur khusus Admin untuk memantau *raw data* dari Google Sheets secara langsung.

Proses Finalisasi

Pastikan semua modul HTML sudah di-*include* di dalam Index.html. Lakukan proses Deploy > Manage Deployments > New version di menu Google Apps Script untuk menerapkan hasil akhir aplikasi ke versi Live.

Selesai — Dokumentasi Web App Sistem Akademik (Google Apps Script).
