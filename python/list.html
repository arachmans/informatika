Bagian 01 • Konsep Dasar

Apa itu List di Python?

List adalah struktur data bawaan di Python yang digunakan untuk menyimpan sekumpulan item dalam satu variabel. List ditulis menggunakan tanda kurung siku [ ] dan setiap elemennya dipisahkan oleh tanda koma.

Terurut (Ordered)

Setiap elemen memiliki posisi indeks tetap mulai dari 0. Urutan tidak berubah kecuali diubah secara eksplisit.

Dapat Diubah (Mutable)

Isi list bisa ditambah, diubah nilainya, maupun dihapus kapan saja setelah list tersebut dibuat.

Tipe Data Campuran

Satu list dapat menampung str, int, float, bool, bahkan list lain di dalamnya.

Mendukung Duplikat

List memperbolehkan adanya elemen dengan nilai yang sama persis karena setiap elemen dibedakan berdasarkan indeksnya.

1. Membuat & Mengubah List

Dasar

List dapat dibuat kosong, berisi nilai seragam, ataupun campuran. Karena bersifat mutable, elemen bisa diganti langsung menggunakan indeksnya. 

# List kosong & list campuran

# Mengubah elemen pada indeks ke-1
campuran[1] = 3.13

3. Slicing (list[start:stop:step])

Irisan

Slicing mengambil sebagian elemen dan menghasilkan list baru. Indeks start bersifat inklusif (ikut), sedangkan stop bersifat eksklusif (berhenti sebelum indeks tersebut). 

angka = [10, 20, 30, 40, 50]

print(angka[1:4])    # [20, 30, 40]
print(angka[:3])     # [10, 20, 30]
print(angka[::2])    # [10, 30, 50] (lompat 2)
print(angka[::-1])   # [50, 40, 30, 20, 10] (dibalik)

4. List Comprehension

Pythonic

Cara ringkas dan elegan di Python untuk membuat list baru berdasarkan perulangan (loop) dan kondisi tertentu hanya dalam satu baris kode. 

# Membuat list kuadrat bilangan 1 sampai 5
kuadrat = [x**2 for x in range(1, 6)]
# Output: [1, 4, 9, 16, 25]

# Dengan filter kondisi (hanya bilangan genap)
genap = [x for x in range(10) if x % 2 == 0]
# Output: [0, 2, 4, 6, 8]
