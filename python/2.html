Level 08

Perulangan: Biar Komputer yang Capek

Komputer paling jago melakukan hal yang sama berulang-ulang tanpa mengeluh. Kamu cukup tulis perintahnya sekali, lalu bilang seberapa banyak atau sampai kapan harus diulang.

🔁

for

Dipakai kalau kamu tahu jumlah putaran atau punya daftar yang mau dijelajahi satu per satu.

⏳

while

Dipakai kalau kamu tahu syarat berhenti, bukan jumlahnya. "Selama nyawa > 0, terus main."

🏭

range()

Pabrik angka untuk for. Angka akhir tidak ikut — ini jebakan paling sering sejuta pemula.

🛑

break & continue

break = keluar total dari perulangan. continue = lewati putaran ini, lanjut ke berikutnya.

range(awal,akhir,langkah)
awal = mulai dari sini (ikut) akhir = berhenti sebelum ini (tidak ikut) langkah = lompat berapa (boleh negatif)
range(5) → 0 1 2 3 4 range(1, 6) → 1 2 3 4 5 range(0, 10, 2) → 0 2 4 6 8 range(5, 0, -1) → 5 4 3 2 1

Level 09

Fungsi: Resep yang Punya Nama

Fungsi itu resep: tulis sekali, panggil berkali-kali. Dia punya bahan (parameter), langkah (badan fungsi), dan hasil (return). Ini awal dari kode yang rapi dan nggak copy-paste.

def hitung_rata(daftar):
    total = 0
    for n in daftar:
        total = total + n
    return total / len(daftar)
def = "aku mau bikin fungsi" nama = panggilan resepnya parameter = bahan yang dikirim pemanggil : + indentasi 4 spasi = awal badan fungsi return = serahkan hasil ke pemanggil

❌ Cuma print, tidak return

Hasilnya cuma muncul di layar. Nggak bisa dipakai menghitung lagi — komputer menerimanya sebagai None.

salah.py
def tambah(a, b):    print(a + b)hasil = tambah(3, 4)   # layar: 7print(hasil)             # None 😱

✅ return: hasilnya bisa dipakai

Nilainya kembali ke pemanggil, jadi bisa disimpan, dihitung lagi, atau dikirim ke fungsi lain.

benar.py
def tambah(a, b):    return a + bhasil = tambah(3, 4)   # 7print(hasil * 2)         # 14 🎉

Rekursi: Fungsi yang Memanggil Dirinya 🪆

Faktorial 5! = 5 × 4 × 3 × 2 × 1. Cara rekursif: 5! = 5 × 4! — fungsi memanggil dirinya dengan angka lebih kecil, sampai menyentuh titik berhenti (n ≤ 1). Tanpa titik berhenti = tumpukan jebol!

faktorial.py
def faktorial(n):    if n <= 1:        return 1    return n * faktorial(n - 1)hasil = faktorial(5)print("5! =", hasil)
