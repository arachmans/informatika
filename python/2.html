Level 08

Perulangan: Biar Komputer yang Capek

Komputer paling jago melakukan hal yang sama berulang-ulang tanpa mengeluh. Tulis perintahnya sekali, lalu bilang seberapa banyak atau sampai kapan harus diulang.

🔁

for

Kalau kamu tahu jumlah putaran atau punya daftar yang mau dijelajahi satu per satu.

⏳

while

Kalau kamu tahu syarat berhenti, bukan jumlahnya. "Selama nyawa > 0, terus main."

🏭

range()

Pabrik angka untuk for. Angka akhir tidak ikut — jebakan paling sering pemula.

🛑

break & continue

break = keluar total. continue = lewati putaran ini, lanjut berikutnya.

range(awal,akhir,langkah)
awal = mulai dari sini (ikut) akhir = berhenti sebelum ini langkah = lompat berapa (boleh negatif)
range(5) → 0 1 2 3 4 range(1, 6) → 1 2 3 4 5 range(0, 10, 2) → 0 2 4 6 8 range(5, 0, -1) → 5 4 3 2 1

LAB 8B

break vs continue — Bedanya Kelihatan ⏭️🛑

Dua program berjalan berdampingan dengan angka yang sama. continue hanya melewati satu putaran; break menghentikan seluruh perulangan. Semua kartu tersusun rapi di dalam kotaknya — tidak ada yang keluar jalur.

🐢🐇

⏭️ continue lewati kelipatan 3

continue.py
for i in range(1, 11):
output continue

🛑 break berhenti setelah 6

break.py
for i in range(1, 11):
output break
▪ belum jalan ✓ sudah jalan ⤼ dilewati (continue) ■ dihentikan (break)

Level 09

Fungsi: Resep yang Punya Nama

Tulis sekali, panggil berkali-kali. Punya bahan (parameter), langkah (badan fungsi), dan hasil (return).

def hitung_rata(daftar):
    total = 0
    for n in daftar:
        total = total + n
    return total / len(daftar)
def = bikin fungsi nama = panggilan resep parameter = bahan dari pemanggil return = serahkan hasil

❌ Cuma print, tidak return

Hasil cuma muncul di layar. Pemanggil menerima None.

salah.py
def tambah(a, b):    print(a + b)hasil = tambah(3, 4)   # layar: 7print(hasil)             # None 😱

✅ return: hasilnya bisa dipakai

Nilai kembali ke pemanggil, bisa disimpan dan dihitung lagi.

benar.py
def tambah(a, b):    return a + bhasil = tambah(3, 4)   # 7print(hasil * 2)         # 14 🎉
