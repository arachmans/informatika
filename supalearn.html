Menghubungkan Supabase dengan Netlify (Implementasi Langsung)

Pelajari arsitektur deployment nyata, uji coba pengiriman data dari aplikasi web yang di-host di Netlify ke database Supabase, dan salin template kode siap pakai.

Langkah 1

Siapkan Tabel & RLS di Supabase

Buat tabel projek_informatika di Supabase, aktifkan RLS, dan tambahkan Policy FOR SELECT serta FOR INSERT.

Langkah 2

Set Environment Variables Netlify

Di Site Configuration > Environment Variables Netlify (atau lewat Supabase Extension), simpan VITE_SUPABASE_URL dan VITE_SUPABASE_ANON_KEY.

Langkah 3

Daftarkan Site URL di Supabase

Masukkan domain https://nama-app.netlify.app ke menu Authentication > URL Configuration di dashboard Supabase.

Langkah 4

Deploy Otomatis / Netlify Drop

Push ke GitHub untuk Auto-Deploy dengan netlify.toml, atau tarik folder HTML ke app.netlify.com/drop.
